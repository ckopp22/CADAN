# CADAN

A medieval-themed roll-and-write dice game for 1-6 players, played pass-and-play on one device. Built with plain HTML, CSS and JavaScript (no frameworks, no build step).

CADAN is being built in small sections following the plan in [MDD.md](MDD.md).

## Running locally
Open `index.html` in a browser, or serve the folder with any static server. All paths are relative, so it also works from GitHub Pages.

## Adjusting the game
- Costs, turn limits and the X penalty: `data/constants.js`
- Island One hexes, slot points, road links and map coordinates: `data/island-one.js`
